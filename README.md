## Projects

### Samepage

Website briefs for studios and their clients, done as a chat. A studio asks six questions, the client answers and sends the brief, and the studio approves one version or sends it back with a note.

**[Try the live demo](https://samepage.mosalah-77.workers.dev)** · [Code](https://github.com/mosalah-77/samepage) · [How it works](https://github.com/mosalah-77/samepage/blob/main/docs/how-it-works.md) · [Decisions](https://github.com/mosalah-77/samepage/blob/main/docs/decisions.md)

![Samepage: the client's side of a brief](https://raw.githubusercontent.com/mosalah-77/samepage/main/docs/screenshot-light.png)

React and TypeScript on a Cloudflare Worker with a D1 database. The server keeps each client's work separate, handles two people saving at once, makes retries safe and stores uploaded files privately. It has 51 automated checks, a clean accessibility scan, security headers and rate limits. I scoped it, chose the stack, took the design through several rounds and reviewed the build.

### FixCity

Report a problem with a road or a streetlight and follow it through staff review to repair.

[Open the browser demo](https://mosalah-77.github.io/FixCity/) · [Watch the Android walkthrough](https://github.com/mosalah-77/FixCity/releases/download/v1.1.1-demo.1/fixcity-demo-1.1.1.mp4) · [Download the APK](https://github.com/mosalah-77/FixCity/releases/tag/v1.1.1-demo.1) · [Code](https://github.com/mosalah-77/FixCity)

Flutter, Dart and Supabase. FixCity began as our six-person BIS graduation project. I worked on the user flows, shared the technical direction and built parts of the frontend, then extended it for this portfolio. The demo uses made-up data and is not an official government service. The [original repository](https://github.com/moatazahmedshaker/Fixcity), Ahmed Wael Ali / DoctorJhin and the original team are credited in the project README and history.
